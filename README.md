# Wizzard starter site

A deliberately tiny website for the Wizzard AI bootcamp: one page, one stylesheet, one script, and a `CLAUDE.md` that tells Claude how to work on it. You'll make your own copy, put it live on the internet, then build on it with Claude Code.

## What's in the box

| File | What it does |
|---|---|
| `index.html` | The page itself: the words and the structure |
| `styles.css` | How it looks: fonts, colours, spacing |
| `script.js` | Anything interactive (empty for now) |
| `CLAUDE.md` | Your brief for Claude. Fill in the ✏️ sections first |

## Steps

1. **Make your own copy.** Click **Use this template → Create a new repository**. Give it a short name, leave it **Public**, and click **Create repository**.
2. **Put it live.** Sign in to [vercel.com](https://vercel.com) with GitHub, click **Add New → Project**, pick your repository and click **Deploy**. No settings to change. In under a minute you'll have a real web address.
3. **Brief Claude.** Open [claude.ai/code](https://claude.ai/code), pick your repository, and ask Claude to help you fill in `CLAUDE.md` for your idea.
4. **Build.** Ask for one change at a time. Claude saves its work to a new branch, and Vercel gives each branch its own preview link.
5. **Ship it.** When you're happy, ask Claude to open a pull request, then merge it on GitHub. Your main web address updates within a minute.

## Good to know

- Everything here is public, so use made-up data only.
- There's no database. Anything a page "saves" stays in that one browser.
- Vercel's free Hobby plan is for personal, non-commercial projects. Real client work would need a paid plan.
